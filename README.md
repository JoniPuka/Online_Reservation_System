
# Online Reservation System

## Overview

The Online Reservation System is a Java-based application developed to manage online reservations using MySQL as its database. The project was created as part of my software development learning journey, applying programming and database management concepts to a practical application.

It demonstrates the integration of Java with a relational database to store, retrieve, and manage reservation-related information.

## Technologies Used

- **Java** — Application logic and object-oriented programming
- **MySQL** — Relational database management
- **JDBC** — Database connectivity between Java and MySQL (if used)

## Key Features

- Reservation management
- Database integration using MySQL
- Storage and retrieval of reservation information
- Structured data management through a relational database

## Getting Started

### Prerequisites

- Java Development Kit (JDK)
- MySQL Server
- An IDE such as IntelliJ IDEA or Eclipse (optional)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/JoniPuka/Online_Reservation_System.git
   ```

2. Open the project in your preferred Java IDE.
3. Set up the MySQL database using the project's SQL scripts or schema.
4. Configure the database connection.
5. Run the application's main Java class.
